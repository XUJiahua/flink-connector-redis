# Redis connector 2.2.6.1

本版本基于 **v2.2.6**，为 Sink V2（SQL 路径）增加分段延迟与积压指标，帮助定位 Flink 计算、sink 内部等待和 Redis 命令往返的耗时。指标无需新增 WITH 配置，原有写入配置保持兼容。本版本属于 v2.2.6 维护线，不包含 v2.2.7 至 v2.2.10 的后续改动。

## 变更

- 增加 `redis_sink_invoke_delay_ms`、`redis_sink_buffer_wait_ms`、`redis_sink_cmd_latency_ms` 和 `redis_sink_ack_freshness_ms`，提供 histogram、最近 60 秒最大值与最近样本值。
- 增加缓冲记录数 `redis_sink_buffer_size`、在途主命令数 `redis_sink_pending_commands` 与时间基准来源 `redis_sink_event_time_source`。
- 指标注册或采样遇到 `RuntimeException`、`LinkageError` 时关闭延迟指标并记录告警，继续执行 Redis 写入；其他 Error 不在此降级范围内。

## 指标口径

- `invoke_delay` 与 `ack_freshness` 优先使用记录时间戳；缺失时回退到 watermark + 1，此时为上界估计，低流量下可能明显偏大。没有可用时间基准时，这两个指标不产生样本。
- 定位 sink 等待和 Redis 往返耗时，应结合 `buffer_wait`、`cmd_latency` 与 `pending_commands`。命令延迟仅统计主写命令，不包含附加的 TTL EXPIRE。
- 时间戳与 TaskManager 墙钟比较要求时间口径一致，时钟偏差也会影响结果。详细口径和 PromQL 示例见 [README](https://github.com/XUJiahua/flink-connector-redis/blob/v2.2.6.1/README.md#36-sink-分段延迟指标)。

## 运行与下载

构建基线为 Java 11、Flink 2.2.1；Redis 集成测试使用 Redis 7。

- `flink-connector-redis-2.2.6.1-jar-with-dependencies.jar`：包含运行依赖，适合直接部署到 Flink lib 目录。
- `flink-connector-redis-2.2.6.1.jar`：普通 JAR，适合由部署环境提供运行依赖的场景。
- `SHA256SUMS`：下载 JAR 后，可在同一目录执行 `sha256sum -c SHA256SUMS` 校验。

本次通过 GitHub Release 分发，不发布到 Maven Central。
